ProTemplateHQ Shop Manager

A private, self-hosted tool for managing my own Etsy shops.

About the project

I run a small print-on-demand and digital pattern business on Etsy. This tool runs on my own computer and helps me keep the listings in my own shops organized and up to date. It is not a public app, it is not sold, and it is not offered to other sellers.

What it does

  • Creates and edits listings in my own shops: title, tags, description and attributes.
  • Uploads listing images and videos that I produce for my products.
  • Organizes listings into shop sections.
  • Reads my own shop's listings and orders for bookkeeping and profit tracking.

What it does not do

  • It does not access other sellers' shops or data.
  • It does not need or request commercial API access.
  • It does not share or sell any data. Order data stays on my own computer and is used only for my own accounting.

Technology

Node.js and Express running locally, using the official Etsy Open API v3 with OAuth 2.0 (PKCE). Requests are rate-limited to stay within Etsy's API limits.
